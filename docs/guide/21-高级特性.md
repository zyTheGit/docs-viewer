## 注入作用域（Scope）

Provider 默认是**单例**（`Scope.DEFAULT`）：整个应用生命周期只创建一次。

### 三种作用域

```typescript
import { Injectable, Scope } from '@nestjs/common';

@Injectable({ scope: Scope.DEFAULT })   // 单例（默认，性能最好）
export class AppService {}

@Injectable({ scope: Scope.REQUEST })   // 每个请求一个实例
export class RequestService {}

@Injectable({ scope: Scope.TRANSIENT }) // 每次注入都是新实例
export class TransientService {}
```

| 作用域 | 生命周期 | 内存开销 | 典型用途 |
|--------|----------|----------|----------|
| DEFAULT | 应用级单例 | 最低 | 绝大多数 Service |
| REQUEST | 每请求新建 | 高 | 请求级缓存、多租户上下文 |
| TRANSIENT | 每次注入新建 | 中 | 独立状态的工具类 |

### REQUEST 作用域注意事项

1. **性能**：每请求创建整条依赖链实例，GC 压力大，能用单例+上下文传递就不用 REQUEST。
2. **传染性**：依赖 REQUEST 的 Provider 会强制其所有依赖者变为 REQUEST。
3. **Controller 也可设置**：`@Controller({ path: 'users', scope: Scope.REQUEST })`。
4. **在单例中取请求上下文**：用 `ContextIdFactory` 而不是把 REQUEST 注入单例：

```typescript
import { ContextIdFactory } from '@nestjs/core';

@Injectable()
export class UsersService {
  constructor(
    @Inject(REQUEST) private requestContext: any,
  ) {}
}

// 或在单例 Service 中按请求 id 解析
const contextId = ContextIdFactory.getByRequest(req);
this.moduleRef.resolve(RequestService, contextId);
```

## 生命周期钩子全解

按调用顺序（NestJS 12 起按**组件层级**顺序触发，注意升级后初始化顺序可能与 v11 不同）：

| 钩子 | 接口 | 时机 | 用途 |
|------|------|------|------|
| `onModuleInit` | `OnModuleInit` | 模块依赖解析完成后 | 连接数据库、预热 |
| `onApplicationBootstrap` | `OnApplicationBootstrap` | 应用完全启动后 | 开始消费队列、定时启动 |
| `onModuleDestroy` | `OnModuleDestroy` | 收到关闭信号后 | 释放模块资源 |
| `beforeApplicationShutdown` | `BeforeApplicationShutdown` | 所有 destroy 之后 | 停止接受新请求 |
| `onApplicationShutdown` | `OnApplicationShutdown` | 连接关闭后 | 最后清理 |

```typescript
@Injectable()
export class DbService implements OnModuleInit, OnApplicationShutdown {
  async onModuleInit() {
    await this.connect(); // 初始化连接
  }

  onApplicationShutdown(signal?: string) {
    this.close();         // SIGTERM 时优雅断开
  }
}
```

### 启用关闭钩子

生产环境必须开启，否则 `SIGTERM` 不会触发 destroy 钩子：

```typescript
// main.ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.enableShutdownHooks(); // 监听 SIGTERM/SIGINT
  await app.listen(3000);
}
```

## 动态模块进阶

### 静态配置 + 异步工厂

```typescript
@Module({})
export class RedisModule {
  static register(options: RedisOptions): DynamicModule {
    return {
      module: RedisModule,
      providers: [{ provide: REDIS_OPTIONS, useValue: options }],
    };
  }

  static registerAsync(options: {
    imports?: Type<any>[];
    useFactory?: (...args: any[]) => RedisOptions | Promise<RedisOptions>;
    inject?: any[];
  }): DynamicModule {
    return {
      module: RedisModule,
      imports: options.imports,
      providers: [
        { provide: REDIS_OPTIONS, useFactory: options.useFactory, inject: options.inject },
      ],
    };
  }
}

// 使用
RedisModule.register({ host: 'localhost' });
RedisModule.registerAsync({
  imports: [ConfigModule],
  inject: [ConfigService],
  useFactory: (config) => ({ host: config.get('REDIS_HOST') }),
});
```

### 模块导出与 Provider 转发

```typescript
@Module({
  imports: [UsersModule],           // 导入才可注入其导出项
})
export class OrdersModule {}

// 无法直接导入但有 token 时，用 ModuleRef 动态获取
constructor(private readonly moduleRef: ModuleRef) {}
const service = this.moduleRef.get(UsersService, { strict: false });
```

## 自定义装饰器

### 组合装饰器（Decorator Composition）

把常用装饰器打包：

```typescript
// common/decorators/auth.decorator.ts
import { applyDecorators, UseGuards } from '@nestjs/common';
import { ApiBearerAuth, ApiUnauthorizedResponse } from '@nestjs/swagger';

export function Auth(...roles: Role[]) {
  return applyDecorators(
    SetMetadata('roles', roles),
    UseGuards(JwtAuthGuard, RolesGuard),
    ApiBearerAuth(),
    ApiUnauthorizedResponse({ description: '未授权' }),
  );
}

// 使用：一行顶四行
@Auth(Role.Admin)
@Delete(':id')
remove(@Param('id') id: string) {}
```

### 类型安全元数据（Reflector.createDecorator）

Nest 推荐的现代写法（CLI `nest g decorator` 默认生成此形式）：

```typescript
// roles.decorator.ts
import { Reflector } from '@nestjs/core';
import { Role } from '../enums/role.enum';

export const ROLES_KEY = 'roles';
export const Roles = Reflector.createDecorator<Role[]>();

// 使用
@Roles([Role.Admin, Role.User])
```

```typescript
// 守卫中读取
import { Reflector } from '@nestjs/core';

@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const roles = this.reflector.getAllAndOverride<Role[]>(Roles, [
      context.getHandler(),   // 方法级
      context.getClass(),     // 类级
    ]);
    if (!roles) return true;
    const { user } = context.switchToHttp().getRequest();
    return roles.includes(user.role);
  }
}
```

### 参数装饰器

```typescript
// 获取当前用户
export const CurrentUser = createParamDecorator(
  (data: string | undefined, ctx: ExecutionContext) => {
    const request = ctx.switchToHttp().getRequest();
    const user = request.user;
    return data ? user?.[data] : user;
  },
);

// 使用
@Get('profile')
profile(@CurrentUser('id') userId: number) {}
```

## 懒加载模块

某些模块（如重型的通知模块）只在真正需要时才初始化：

```typescript
// app.module.ts
@Module({
  lazy: true,             // 声明为懒加载
  imports: [HeavyModule],
})
export class LazyAppModule {}
```

运行时按需加载：

```typescript
const lazyModuleRef = await LazyModuleLoader.load(() =>
  import('./lazy/lazy.module'),
);
const { LazyModule } = await import('./lazy/lazy.module');
const moduleRef = await lazyModuleRef.load(() => LazyModule);
const heavyService = moduleRef.get(HeavyService);
```

> 💡 懒加载在 monorepo/服务端复用 Nest 容器场景最有价值；普通 HTTP 应用一般用不到。

## 热重载（Hot Reload）

免编译直接热替换代码，加快开发迭代：

```bash
npm i --save-dev webpack shelljs
```

```typescript
// webpack-hmr.config.js
const nodeExternals = require('webpack-node-externals');
const { RunScriptWebpackPlugin } = require('run-script-webpack-plugin');

module.exports = {
  entry: ['webpack/hot/poll?100', './src/main.ts'],
  target: 'node',
  externals: [nodeExternals({ allowlist: ['webpack/hot/poll?100'] })],
  module: { rules: [{ test: /\.tsx?$/, use: 'ts-loader', exclude: /node_modules/ }] },
  mode: 'development',
  resolve: { extensions: ['.tsx', '.ts', '.js'] },
  plugins: [new webpack.HotModuleReplacementPlugin(), new RunScriptWebpackPlugin({ name: 'server.js' })],
};
```

```typescript
// main.ts 追加
declare const module: any;
if (module.hot) {
  module.hot.accept();
  module.hot.dispose(() => app.close()); // 重载前优雅关闭
}
```

```bash
# package.json
"start:hot": "nest build --webpack --webpackPath webpack-hmr.config.js --watch"
```

## 路由版本控制

同一资源同时服务多个 API 版本：

```typescript
// main.ts 启用
app.enableVersioning({
  type: VersioningType.URI,       // /v1/users
  // type: VersioningType.HEADER, // 自定义头
  // type: VersioningType.MEDIA_TYPE,
  defaultVersion: '1',
});
```

```typescript
@Controller({ path: 'users', version: '1' })
export class UsersControllerV1 {}

@Controller({ path: 'users', version: '2' })
export class UsersControllerV2 {}

// 单个方法级
@Get()
@Version('2')
findV2() {}
```

## 原生 HTTP（Fetch）

Node 18+ 内置 `fetch`，Nest 不再强制依赖 Axios；需要更完整能力可用 `@nestjs/axios` + `HttpModule`：

```typescript
// 使用原生 fetch（零依赖）
@Injectable()
export class GithubService {
  async getUser(username: string) {
    const res = await fetch(`https://api.github.com/users/${username}`);
    if (!res.ok) throw new HttpException('上游服务错误', 502);
    return res.json();
  }
}

// 或使用 HttpModule（拦截器友好、类型化）
import { HttpModule } from '@nestjs/axios';
@Module({ imports: [HttpModule] })
export class AppModule {}

constructor(private http: HttpService) {}
await firstValueFrom(this.http.get('https://api.github.com/users/tom'));
```

## 优雅关闭

生产部署零停机的关键组合拳：

```typescript
// main.ts
async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableShutdownHooks();        // 1. 监听 SIGTERM

  const server = app.getHttpServer();
  server.keepAliveTimeout = 65000;  // 2. 大于负载均衡的空闲超时（如 ALB 60s）

  await app.listen(3000);
}
```

```typescript
// 3. Provider 侧在 onApplicationShutdown 中断开连接池/消费者
onApplicationShutdown() {
  this.redis.disconnect();
}
```

配合 Nginx/ALB 的 `drain` 策略与 K8s `terminationGracePeriodSeconds`，即可实现滚动发布不丢请求。
